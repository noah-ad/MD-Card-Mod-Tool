# 2.0.31 验证记录

日期：2026-10-23。Windows x64，.NET 8，真实游戏资源只读，所有写回均针对新建临时 LocalData 镜像。

## 已验证

- Release x64 构建成功，0 错误；365 条现有可空性等警告，新增 Duel 文件无编译警告。
- 只读识别当前已下载资源：52 个场地条目、98 个近端／远端模型、40 个有官方缩略图的场地、159 个 BGM。
- 游戏内简体中文物品字典解析；“森林”、完整物品编号和三位场地编号搜索；主视觉页搜索方法和独立窗口中文搜索均通过。
- 森林 → 齿轮镇：镜像中近端与远端一并替换，来源主资源 PathID 与目标 CAB／容器身份核对，替换后场地纹理可重开解码；还原后两个目标均逐字节等于首次原版。
- 来源缺变体、提交前故障、写锁冲突、损坏备份均拒绝且不覆盖原文件。
- 第一份模型提交后注入失败，已提交模型回滚至逐字节原样；提交前外部追加修改会被检测并保留。
- 官方 BGM 互换后音频流与来源一致，目标 AudioClip 名称保留；还原逐字节一致。
- 原版 Vorbis FSB5 经 vgmstream 解码为 WAV。
- 生成一秒 440 Hz 测试音，导入为含整曲循环数据的 PCM FSB5，重开 Bundle 核对音频字节并再解码；还原逐字节一致，首次备份不变。
- 简体中文、繁体中文、日语、英语窗口构造；窗口加载、目标与来源缩略图、中文筛选通过。查看自动截图，确认两侧缩略图和替换／还原操作区可见。
- 对测试涉及的真实游戏文件逐一复核 SHA-256，均未改变。
- 自包含单 EXE 发布包执行相同整套测试通过；确认 vgmstream EXE／DLL、FFmpeg、目录和许可独立保留在 `data`。打包前已修复音频工具被收入单 EXE 而无法按外部路径启动的问题。
- 现有资源预览滚动回归通过 96／144／192 DPI 注入及多种窗口高度；该回归不等同于实机跨屏 DPI 验收。
- NuGet 继续提示已有 ImageSharp 3.1.12 依赖公告；本次未升级该依赖，不能将构建成功表述为已解决依赖公告。

