# MD Card Mod Tool 2.0.31

2026-10-23，发布至 `noxargenta/MD-Card-Mod-Tool`。普通发行版；新功能仍为实验性，游戏内效果尚未验收。

- 视觉资源页新增“场地与音乐”入口：分别选择目标和来源，按已下载资源显示场地模型、官方缩略图及背景音乐。
- 场地支持中文名称、其他已下载语言名称、三位编号和完整物品编号搜索；名称从当前账号游戏内 `IDS_ITEM` 字典读取，不编造缺失名称。
- 场地来源替换目标全部已下载近端／远端质量变体。来源缺少对应模型或依赖时拒绝整次操作；保留目标 Bundle 标识、容器和资源流定位。官方缩略图用于识别，不是实时 3D，也不自动改成替换后的场景图。
- 音乐可选择已下载官方 BGM 互换，或导入 WAV／MP3／OGG／FLAC 等音频。自定义音频转为 48 kHz、双声道、16 位 PCM FSB5，设置整曲循环，最多 10 分钟。PCM 文件比原版压缩音乐大；游戏中播放和循环行为仍需实测。
- 目标／来源音乐均可本地试听。随包加入 vgmstream r2117 及许可，解码原版 Vorbis FSB5 和生成的 PCM FSB5；音频文件导入使用 FFmpeg。
- 场地／音乐首次备份位于 `<游戏目录>/_MD卡图备份/场地与音乐`，绑定账号、目标路径和 Steam Build，记录 SHA-256。支持还原；不覆盖无法识别的外部改动或损坏备份。
- 全部目标先在临时 Bundle 中构建、重开校验，再锁定、复核与提交；多模型失败尝试回滚，回滚失败保留恢复副本并报告路径。
- 视觉资源页搜索框可见，搜索保持当前视觉分类范围；新场地和替换后更名的场地贴图仍可识别。

## 使用

1. 先在游戏内下载需要的场地与 BGM，再完全退出游戏。
2. 顶栏选对游戏目录与账号，进入“视觉资源 → 场地与音乐”。
3. 选择场地或背景音乐，左侧选目标、右侧选来源；场地可输入“森林”等中文名定位。
4. 点击“使用来源替换目标”，或音乐模式下选择“导入音乐文件”。“还原目标原版”恢复首次备份。

## 边界

- 场地模型、场地缩略图、场地音乐绑定各自独立；替换模型不自动改图标、音效或音乐绑定。音乐按单曲资源替换，多个决斗阶段需分别替换对应曲目。
- 缺缩略图的模型仍列出真实编号；缺模型的缩略图可查看，但不能用于完整场地替换。仅支持当前识别的官方单主资源 Bundle；未知结构安全拒绝。
- 场地与音乐的替换／还原在新窗口操作，不纳入旧图片恢复库或卡片 Mod 列表。需分享时自行备份相应已修改 Bundle，当前没有新增场地／音乐导出包入口。
- 验证仅包含只读本机资源识别、临时游戏镜像写回、解码和 UI 回归。未自动改写真游戏资源，未执行游戏内验收、其他电脑／跨屏 DPI 验收。
- 手机端仍搁置；不增加无原生召唤动画或运行时注入。
