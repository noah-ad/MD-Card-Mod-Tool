# 2.0.31 — 游戏更新后的新卡索引与预览稳定性

- 游戏 Build 变化后，卡图索引会强制完整校验一次，不再只依赖旧 Bundle 的文件时间戳；成功完成后记录 Build，后续启动继续使用增量扫描。
- 资源指纹加入每个 Bundle 的首尾内容采样。即使下载器替换文件时保留长度和时间戳，也会触发新卡目录和卡图刷新。
- 旧索引中的 PathID、Texture2D 名称或逻辑路径失效时，预览／替换会先使用 CRC 候选，再按卡号对应的 Bundle 文件名重新定位并回写缓存，降低“找不到 Texture2D”的情况。
- 扫描改为成功后一次性提交；保留上一次可用列表，避免账号切换、Build 检测或后台刷新时出现空白闪烁。
- 快速切换资源时保留上一张预览直到新资源完成解码；圆角按钮启用双缓冲，并减少重复布局重绘。

本版保留 2.0.30 的 FFmpeg 参数兼容修复、动画图集与超框登记恢复。手机端兼容继续搁置；不向无官方演出的怪兽新增动画，不向真实游戏进程注入。开发写回测试只使用临时副本，真实游戏内显示仍需用户验收。
