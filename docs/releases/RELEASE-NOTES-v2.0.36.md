# 2.0.36 — 中文卡名变体搜索

## 本版重点

- 修复新卡中文译名不同导致的漏搜。搜索索引为每种语言建立窄范围的等价键：去除名称中的“之”、`帘布`/`幕帘`互换，以及 `魔导`/`魔導`互换。
- 不修改游戏原始卡名显示，只扩展检索键；因此 `幕帘`、`黑魔导的幕帘` 可以命中当前游戏字典中的 `黑之魔导的帘布`（22692），同时保留 `14513`、`12747` 等真实匹配。
- 继续继承 2.0.35 的图库缩略图回填、卡名/图片索引分离、Build 自动刷新和本机 MD 主题工作区。

## 限制

- 变体索引只处理明确、对称的常见译名差异，不使用过宽的模糊匹配，避免短词产生大量误命中。
- 卡名收录不代表当前账号已经下载对应图片；未下载时仍显示待定位状态。
