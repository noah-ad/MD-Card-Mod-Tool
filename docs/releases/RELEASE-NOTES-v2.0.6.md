# MD Card Mod Tool 2.0.6

## Mod ZIP

- 导出增加“直接替换 ZIP”，保留游戏资源目录与原 Bundle 文件名；也保留旧版工具专用 .mdmod.zip 格式。
- ZIP 附带安装说明和工具清单。手动安装先备份并核对 LocalData 账号；通过工具导入会自动映射当前选中账号。
- 支持无清单的目录式 Bundle ZIP，包括完整 LocalData、StreamingAssets、0000 和两位哈希子目录结构。
- 导入先校验全部路径、文件大小、SHA-256 与 Unity Bundle 结构，再备份和写入。拒绝越界、重复目标、符号链接、程序文件、损坏资源及未下载的目标。
- 写入要求游戏完全退出；保留首次备份，提交失败回滚。恢复失败时保留恢复副本并提示位置。

## 包含上一轮优化

- 新卡动画根据真实资源路径推导 HD／SD 伴随缩放目录，不限制三位小数；修复 22524 的 HD `0.585` 与 SD `0.2925` 漏配。
- 即使 Steam Build 未变化，也检查新下载动画并补全卡片关联；更新索引采用临时文件原子替换。

- 超框背景可独立拖动、缩放与微调；保持原图及草稿构图。
- 修复 Spine 图集旋转、区域尺寸和裁边 UV；新增其他卡的整套动画替换及来源预览。
- 青金色导航强调、DPI 图标与重绘缓存；修复超框按钮底部裁切和窗口缩放时重复合成。

## 限制

游戏内召唤尚未实测。整套动画替换仅用于已有完整原生动画的目标；不为无动画卡创建触发。复杂 Spine 约束仍需逐卡验证。请使用与游戏版本相容的 Mod，整 Bundle 覆盖会替代同文件内的其他修改。

解压程序包后直接运行根目录的 MD卡图查看替换器.exe，data 文件夹需保留在旁边。旧版目录不覆盖。
