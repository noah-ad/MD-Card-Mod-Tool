# 2.0.32 音乐试听停止修复

修复背景音乐试听中途点击“停止”出现 `The path is empty` 异常的问题。停止时仅停止播放，不再将 SoundPlayer 的音频路径设为空字符串；重复停止、再次试听、切换场地模式及播放时关闭窗口均使用安全的停止路径。

保留 2.0.31 的场地中文搜索、官方缩略图识别、模型替换及音乐互换／导入功能。场地和音乐替换仍为实验功能；官方缩略图并非实时 3D，游戏内加载、播放及循环效果仍未验收。开发写回测试仅针对临时镜像。

验证范围见 `docs/testing/TEST-REPORT-v2.0.32.md`。完整包包含外置 FFmpeg、vgmstream 与许可；已有 ImageSharp 依赖公告未在本次升级解决。
