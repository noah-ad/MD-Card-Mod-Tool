# 2.0.17 单卡闪面去内框实验版

在卡片资源 → 制作超框 → 工具栏新增“去除闪卡／镜碎内框”。默认关闭，按单张卡草稿保存；旧草稿保持关闭。

开启后，按当前卡框模板 ArtFrame / EffFrame 区域（排除 EffBox）设置 Alpha=4，保留 RGB，其他像素不变。不修改公共卡框或其他卡。仍使用原有单卡写入确认、备份流程。

预览和 PNG 导出使用同一处理结果，但工具不能模拟游戏的动态闪面 Shader。此选项可能改变内框附近闪度，尚未验证游戏内最终效果，不保证闪卡/镜碎所有类型均可去框。

使用：打开目标卡的制作超框窗口，勾选实验选项，退出游戏后应用到当前卡，再进游戏分别查看普通、闪卡和镜碎。取消勾选并重新应用，可恢复默认遮罩；原始资源仍可通过 Mod 还原恢复。

本版保留 2.0.16 PC 索引修复。手机兼容继续搁置。独立发布，不覆盖旧程序、不自动写游戏、不上传 GitHub。
