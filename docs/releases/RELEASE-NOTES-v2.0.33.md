# 2.0.33 音乐中文场地注释与整组替换

- 音乐名后显示中文括号注释，包含参考绑定的场地、通常／关键卡／高潮或 A／B／C 阶段，以及共用曲目标记。直接搜索“森林”等中文场地名即可筛出对应曲目。
- 新增“替换整组音乐”：左右选定不同组曲目后，一次替换阶段相同、完整下载的整组曲目。确认窗口列出每个目标及来源，并提示共用曲目会影响多个场地。缺曲目或阶段不同则拒绝，支持继续使用单曲替换；首次备份及按单曲还原保留。
- 修正场地物品编号和模型编号不同造成的中文名称／缩略图错配，例如森林物品 1090001 实际对应模型 Mat_002。模型与物品映射读取当前游戏的 BgMatModelSetting，不再直接假设编号相同。
- 保留 2.0.32 音乐试听停止修复。

场地音乐关联参考 YgoMaster 的社区数据，已注明来源与 MIT 许可；原资料明确标注待定／临时代用的关联不纳入注释。未确认绑定显示“未确认场地绑定”，不推测。名称来自已下载的游戏字典；缺名称显示物品编号。菜单／单人／教程曲目显示用途说明。

已通过临时游戏镜像与完整发布包回归，详见测试报告。未改写真游戏资源；场地／音乐替换仍为实验功能，真实游戏加载、播放、循环及关联准确性尚未验收。官方缩略图不是实时 3D。整组只替换音频资源，不改游戏内绑定表；不支持不同阶段结构的组自动转换。已有 ImageSharp 依赖公告仍保留。
