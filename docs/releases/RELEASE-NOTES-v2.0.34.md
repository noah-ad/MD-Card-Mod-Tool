# 2.0.34：场地与音乐统一 MOD 管理

- 场地模型、背景音乐与卡图共用“MOD 管理”，自动识别 2.0.31–2.0.33 留下的有效替换记录。场地的近端／远端及质量变体合并为一项，导出和还原包含其全部已修改变体。
- 支持导出选中／全部、备份当前 Mod；场地／音乐保存在完整 Bundle ZIP 中，可用“导入 Mod 包”恢复修改。首次原版备份保留，批量还原恢复原版。
- 支持卡图、场地、音乐混合多选批量还原，提交失败整批回滚；保留原有超框登记还原逻辑。
- MOD 列表、场地列表和音乐列表中的已修改项显示黄色字体；恢复原版后恢复正常颜色。关联场地预览同样显示修改标记。
- 备份包导入校验当前账号、游戏 Build、容器、内容哈希和依赖，并记录首次备份。校验异常的修改会显示，但禁止自动还原／导出覆盖。

## 使用与限制

操作前完全退出游戏。场地／音乐原版备份位于游戏目录 `_MD卡图备份/场地与音乐`。使用“备份当前 Mod”时，修改后的完整 ZIP 另存到账号恢复库的“场地与音乐备份”目录，完成提示会显示路径。

包含场地／音乐的新格式包需要 2.0.34 或更新版本，并仅支持相同游戏 Build；不参与跨游戏更新的 PNG 自动重应用。旧图片 Mod 包继续支持。不要删除首次原版备份。

场地与音乐替换仍为实验功能，官方缩略图不是实时 3D 预览。中文音乐关联沿用有版本记录的社区资料，未知绑定不猜测。临时镜像回归不等于游戏内加载、播放、循环效果验收；未改写真游戏资源。手机端继续搁置。

验证详见 [测试记录](../testing/TEST-REPORT-v2.0.34.md)。发布到用户指定的 `noxargenta/MD-Card-Mod-Tool` fork。
