# 2.0.34 — 卡目录与 MD 风格工作区

## 本版重点

- 卡片搜索不再只依赖已建立的图片索引。游戏字典已经收录、但本机尚未下载卡图的卡也会显示，并明确标记为“卡图待定位”。
- 选择待定位卡后，工具只按当前账号的 TCG/OCG 标准路径定位并校验 Texture2D；成功后会写入当前账号索引，失败时不会把错误资源当成目标卡。
- 游戏更新后的 `card_name/card_indx/card_prop` 字典会合并到四语目录。已有字典发现缓存时直接校验已知字典 Bundle，避免每次更新都阻塞在完整 4 万文件扫描；发现路径变化时自动回退到全量发现。
- 卡片资源页改为虚拟化卡片图库，按视口延迟加载缩略图；Mod 管理仍保留原有多选、按修改时间排序和 ZIP 导出适配层。
- 顶部导航改为横向工作区导航，加入本机 Master Duel 的 `GUI_TitleBG` / `GUI_TitleLogo` 主题素材。素材只在用户选择游戏目录后从本机读取，不打包进发行物。
- 保留 150% DPI 的自适应工具栏、预览滚动和旧索引修复逻辑；无图卡片使用稳定占位，不再闪烁成空白列表。

## 已验证范围

- 本机搜索 `22730`、`23875`：卡号和新字典卡名均能进入搜索结果；已下载图片按需显示，未下载图片显示待定位状态。
- `dotnet build` x64 Debug 编译通过。
- UI 工作区回归、卡目录合并和真实游戏目录的字典更新使用临时输出验证；未向真实游戏写入资源。

## 限制

- 卡图只有在当前 Master Duel 账号已下载对应 Bundle 时才能定位和编辑；目录收录不代表本机已经有图片。
- 本版不包含给没有官方召唤演出的卡新增动画，也不向真实游戏进程注入运行时扩展。
