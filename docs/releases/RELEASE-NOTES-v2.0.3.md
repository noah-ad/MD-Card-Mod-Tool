# MD Card Mod Tool 2.0.3

## 连续操作后的 UI 残影修复

- 修复圆角按钮在连续 hover、焦点切换、动画播放、页面往返及窗口／DPI 缩放后，把文字和边框绘制到相邻控件或父容器的问题。
- 圆角按钮改为每个控件独立的 32-bit 离屏缓冲，并一次提交完整客户区；不再共享 WinForms 的全局双缓冲表面，也不再通过会丢失原生裁剪区的 `TextRenderer` 绘制按钮文字。
- 为圆角按钮加入 sibling clipping，并在布局完成后合并重绘旧、新边界，清除移动或缩放控件留下的像素。
- 页面切换与嵌入式怪兽动画页不再使用 `Hide / Show / Application.DoEvents` 或同步 `Update()` 强制重绘，避免嵌套消息循环在半完成布局上绘制旧帧。
- 动画页标题、卡号操作条、右侧操作按钮和超框编辑器在 Per-Monitor V2 DPI 与窗口缩放后统一执行延迟稳定重绘。

## 真实交互回归

- 使用本机卡号 3899 只读回退到官方资源 P13668，依次执行预览、播放、暂停、全部圆角按钮 hover、窗口缩放、卡片页／动画页往返，再与强制整窗重绘结果逐像素比较。
- 超框编辑器依次切换透明、透明炫彩、炫彩、普通四类卡框，并执行卡框切换、卡图缩放、真实 Alpha／构图模式切换、背景图加载及窗口缩放，再进行相同像素比较。
- 最终自包含发布包中，动画页和超框页在交互后与强制重绘分别只有 33 与 31 个焦点边缘像素差异，低于 64 像素阈值；没有出现文字越界、导航残影或按钮旧帧。
- 回归只读取正式游戏资源，超框测试使用临时素材目录；没有写入 Master Duel 文件。

## 保留功能

- 保留 2.0.2 的真实 Alpha 超框预览、透明／透明炫彩／炫彩／普通四类卡框、统一超框编辑器、卡图拖动缩放、叠底背景、四语检索、视觉资源修改和官方怪兽动画预览。
- 发布包根目录仍只有 `MD卡图查看替换器.exe` 与 `data` 文件夹。
