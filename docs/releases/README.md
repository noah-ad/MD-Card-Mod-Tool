## 累计版本摘要

2.0.28 修复新卡自动更新的漏检／中断重试：启动和账号加载后先增量补入实际下载的卡图，不再由卡名字典缓存是否过期决定，也不等动画索引扫描完成；只有全部阶段成功且资源未继续变化才记录本次刷新完成。取消、读取失败、只有旧扫描标记却没有卡图条目的 Bundle 会再次检查；卡名更新后同步刷新当前搜索结果。22730 的游戏简中名是 **四天之龙 暗反叛超量龙**，可搜 `22730`、`四天` 或 `暗反叛`；内置目录同步补充已验证的游戏卡名，后续新卡仍按下载资源自动发现，不硬编码个别卡号。详见 [2.0.28 说明](RELEASE-NOTES-v2.0.28.md) 与 [验证记录](../testing/TEST-REPORT-v2.0.28.md)。本版为 GitHub 最新普通发行版，并包含 2.0.24–2.0.27 的改动；2.0.19 保留为回退版本。发行状态不改变各实验功能的验证边界。

2.0.27 修复 Mod 导出多选交互：**卡片资源 → Mod 管理，直接点击多行即可多选，再次点击取消**，无需一直按住 Ctrl。列表显示勾选标记与选中高亮，“导出选中（数量）”实时显示打包范围；增加“全选当前列表”和“清空选择”。仍支持 Ctrl 切换、Shift 连选；列表获得焦点后 Ctrl+A 全选、Esc 清空、空格切换当前行。普通资源页保持单选。补齐虚拟列表的范围选择通知，并合并连续选择产生的预览请求；切回全部资源时不再因工具栏焦点转移而意外重新进入 Mod 管理。详见 [2.0.27 说明](RELEASE-NOTES-v2.0.27.md) 与 [验证记录](../testing/TEST-REPORT-v2.0.27.md)。改动已并入 2.0.28 发行包。

2.0.26 增加“卡片资源 → Mod 管理 → 一键恢复 Mod”，用于 **Master Duel 游戏更新后重新应用图片修改**，不是还原成原版。新制作、替换、导入的图片 Mod 会按游戏目录与账号保存最终 PNG 和超框登记意图；恢复时在当前 Bundle 副本中核验像素，再事务提交，超框登记仅合并单卡，不覆盖新版整张表。旧超框可从保存素材、背景构图和卡框设置重新生成，需核对旧草稿候选。以前的备份保留在 `_MD卡图备份/更新恢复`，恢复后的“还原所选”使用恢复前当前资源作为基线。

工具运行时每 60 秒在后台检查 Steam Build 及已下载资源变化，动画编辑／写入期间暂停；新卡 ID 检测不再依赖旧卡名列表，下载字典后自动合并四语卡名与动画关联。卡名字典缺失时仍收录已下载卡图，暂用卡号显示；不会生成名称或给无原生动画卡自动创建动画。详见 [2.0.26 说明](RELEASE-NOTES-v2.0.26.md) 与 [验证记录](../testing/TEST-REPORT-v2.0.26.md)。改动已并入 2.0.28 发行包。

**恢复边界**：游戏更新前可点击“保存现有 Mod 到恢复库”保护仍有效的旧图片 Mod。已被覆盖且没有修改素材、恢复库或 ZIP 的内容，只有原版备份无法找回。图片恢复不包含动画、模型、材质或未知资产；动画仍应单独导出兼容版本的 ZIP。恢复库位于 `%LocalAppData%/MDCardModTool/mod-recovery-v1`，不会跟随 EXE 版本目录被清理；不跨账号混用。

2.0.25 修复 1024 等宽度的卡图被“制作超框”固定尺寸判断拒绝的问题：按卡号、资源来源与插图布局识别，打开前重新读取 Bundle 并修正旧索引尺寸，缺失补全、卡框分类及高分辨率灵摆映射同步兼容。普通替换保留实际尺寸；超框制作输出仍为 704×1024。反馈电脑的具体 Bundle 未取得，不能将本机副本回归视为对方文件已验证。详见 [2.0.25 说明](RELEASE-NOTES-v2.0.25.md) 与 [验证记录](../testing/TEST-REPORT-v2.0.25.md)。改动已并入 2.0.28 发行包。

2.0.24 在 Mod 管理中增加“导出选中 Mod”及 Ctrl／Shift 多选，可单独保存直接替换 ZIP 或工具包。默认按修改时间由新到旧排列，支持最早／名称排序，排序与语言切换后保留选择。所选卡已修改的动画和超框登记一起打包；共享 Bundle 仍按完整文件导出，并在导出前提示。详见 [2.0.24 说明](RELEASE-NOTES-v2.0.24.md) 与 [验证记录](../testing/TEST-REPORT-v2.0.24.md)。

2.0.23 修正灵摆卡图写入比例：游戏的完整插图画布高于卡框的可见插图区，不能把构图结果拉伸铺满整张纹理。新版按本机游戏 CardPicture 的实际布局生成纹理，主界面与卡框预览使用相同的可见区域。六种普通灵摆卡框的实际构图、拖动／缩放、临时 Bundle 写回和游戏布局模拟回归通过，真实游戏仍待用户实测。**旧版已经写入变形的 Mod 需重新选择原图片并替换，不会自动改写。**详见 [2.0.23 说明](RELEASE-NOTES-v2.0.23.md) 与 [验证记录](../testing/TEST-REPORT-v2.0.23.md)。改动已并入当前发行版。

保留 2.0.22 的青眼白龙、废品同步士等 StreamingAssets 内置卡图修复、旧索引补全，以及视觉资源中的属性、星级和共享界面图集修改。图标修改影响所有使用该共享资源的卡片。2.0.22 的全画布灵摆比例方案已由本次修正取代，详见 [2.0.22 说明](RELEASE-NOTES-v2.0.22.md)。

新增“怪兽动画 → 画质/单帧最长边 → 原分辨率 · RGBA32（实验）”。选中后重新导入素材，建议图集上限 8192。不缩图、不用 BC7；按已登记页容量生成多页，容量不足明确拒绝。导入时显示内存预估，游戏兼容性仍需实测。详见 [2.0.21 说明](RELEASE-NOTES-v2.0.21.md) 与 [测试记录](../testing/TEST-REPORT-v2.0.21.md)。实验选项已并入当前发行版，不另提供旧预发行包。

2.0.19 修复自定义卡框开启“去除闪卡／镜碎内框”后找不到 `__custom__` 模板、无法生成和应用的问题。自定义 PNG 保持不变，闪面遮罩按当前卡片类型选取；卡片类型未知时使用效果怪兽默认模板。

同时包含 2.0.16–2.0.18 修复：电脑端污染索引自动备份及重建、Mod 列表恢复显示、拒绝跨目录索引写入，以及应用前等待最新超框合成完成并显示具体生成错误。

**单卡去内框仍是实验功能**：卡片资源 → 制作超框 → 勾选“去除闪卡／镜碎内框”。默认关闭，仅改变当前卡的 Alpha 遮罩，不修改公共卡框。可能影响局部闪度；游戏内闪卡/镜碎效果尚未验收。关闭选项并重新应用可恢复默认遮罩。像素及编辑器测试通过，不等同于游戏效果已验证。

手机端兼容已暂停开发和测试，保留已有代码但不承诺可用。本次源码由残存 2.0.15 程序恢复后修复，过程与局限见 [源码恢复记录](../recovery/RECOVERY-REPORT.md)。

2.0.12 修复动画别名及配套资源漏匹配：涵盖 6969 的 P9696、14581 的 _noait_、18825 的 ForUnity，以及 22341 的 img 非数字目录。3899 可定位自身动画并替换。按官方依赖与容器归属识别，不硬编码卡号映射；打开动画时补齐后续图集页，后台重建和缺失补全也使用新规则。原版多页预览有安全尺寸限制，复杂材质特效仍可能出现粉色块，与游戏不完全一致。临时副本写回、预览、回滚和还原通过；真实游戏召唤效果未验收。

2.0.11 增加 8192 动画图集选项并同步写入校验，默认仍为 4096。8192×8192 单张 RGBA 约 256 MiB，处理峰值更高；空间上限不改变游戏内显示比例。实际 8192 图集的临时 Bundle 写回、预览、回滚和还原测试通过；真实游戏播放兼容性尚未验收。

2.0.10 修复资源页右侧预览被挤压的问题：保留预览高度，空间不足时整区深色滚动，图片仍等比显示。导入 Mod 后不再强制切到“仅显示 Mod”；重新扫描卡图时以目标 Bundle 路径识别卡号，并刷新重打包后的资产定位，避免 22524 等卡因内部名称／PathID 改变而丢失。旧索引中已经错认的卡可通过重建索引恢复。

2.0.9 按用户指定重新校准动画比例：**新版 100% = 2.0.8 的 140%**，生成画布为 6720×3780。旧版动画按实际附件尺寸换算显示，不会自动重写 Mod。这是手动校准，不保证所有卡在游戏中都完全铺满；放大可能裁切边缘。

同时包含 2.0.7／2.0.8 的文件占用预检、六 Bundle 临时验证与回滚、同一 Steam Build 下新卡名称自动刷新（22920「小丑戏帮 哈特」）、以及侧栏初始 DPI 修复。

新版本需重新导入并替换动画，已写入游戏的旧动画不会自行改变。非 16:9 素材仍保持原比例，可能留边；不会拉伸内容。首次读取新资源会在后台刷新卡名。DPI 测试包含注入初始 144/192 DPI 的构造回归，但不等于真实桌面或跨屏测试；未进行实际游戏召唤验收。

面向《游戏王 Master Duel》的 .NET 8 x64 资源查看与 Mod 制作工具。2.0.5 加入超框背景独立构图、其他卡动画整套替换，修复旋转／裁边图集导致的预览肢体错位，并减少界面重绘和动画解码开销。卡套／灵摆正常比例编辑及 EXE + data 启动布局继续保留。
