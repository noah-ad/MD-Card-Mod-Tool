# 2.0.29 — 官方动画识别、图集漏页与超框还原

## 动画资源

- 修正把“未找到完整 Spine 资源”当成“没有官方动画”的提示，简中、繁中、日语和英语同步更新。
- 按官方 Prefab 的依赖链寻找资源，继续遍历中间 Timeline／材质 Bundle；资产归属以容器路径为准，不要求贴图／骨骼名必须等于卡号。旧索引的 Bundle 仍存在时也重新读取资产位置，避免继续使用失效的 PathID。
- 按 Atlas 实际声明的全部页名计算并查找资源路径，不只读首页或猜测固定数字后缀。本机发现并补齐 7302、10783、19152、19633、20196、20280、21038 的后续图集页。替换资格要求同一地区的 HD/SD 配对完整，缺少后续页时不会启用替换。
- 同一个游戏 Build 下，旧动画索引会按解析器版本补查；卡片资源中的官方动画标记包括已发现的非 Spine 官方演出。可替换的 Spine 来源列表与“存在官方演出”分开处理。
- 动画页增加只读“资源诊断”，展示已找到的 Bundle、容器和缺失依赖，不写游戏文件。

**14741「原始生命态 尼比鲁」的实际情况**：本机找到其 HD/SD 官方 Prefab、Timeline 和特效资源，但它不是 Spine 骨骼／Atlas 六资源演出。23487、23488 同属此类。新版能识别并明确显示“已找到官方 Timeline 演出”；**本版仍不支持这三张的原生 Timeline 播放或动画替换**，不是给它们补造 Spine，也不会谎报可以替换。未知或未下载的资源会显示未定位／不完整，不再断言没有官方演出。

## 还原图片 Mod 时恢复超框登记

- 不再依赖“超框卡图”分类文字判断是否还原开关；从 Mod 管理、普通卡图分类或缓存过期列表还原时都按卡号处理。
- 还原原始贴图的同时，把所选卡的 `of_card_asset` 登记恢复为当前备份中的原始行：后来添加的超框关闭，原生官方超框恢复原映射；其他卡的登记保留。
- 支持 Mod 管理多选后“还原所选”，按完整 Bundle 去重。共享 Bundle 的其他贴图仍会随文件一起还原。
- 贴图和登记表先在副本中验证，再持有写入租约提交；任一步失败会一起回滚，不留下只改贴图或只改开关的半成品。缺少必要的登记备份时停止并说明原因，不盲目删除官方登记。
- 成功后刷新资源尺寸、资产位置和分类，并停用所选 Mod 的恢复库登记，避免之后“一键恢复 Mod”重新启用已还原的修改。

## 验证与边界

本机对 518 张已下载官方动画候选进行只读归属／配对审计，区分 515 张 Spine 候选和 3 张原生 Timeline；逐帧渲染不等于全游戏验收。7 张漏页卡另行执行补页回归。所有写回测试都在独立镜像执行，不修改真实游戏资源。具体入口和结果见 [验证记录](../testing/TEST-REPORT-v2.0.29.md)。

需要彻底退出 Master Duel 后再替换或还原。复杂 Spine 材质／约束的预览与游戏仍可能不同；其他玩家电脑、真实游戏召唤和跨屏 DPI 未验收。手机端继续搁置，不恢复给无官方演出怪兽新增动画或进程注入的功能。
