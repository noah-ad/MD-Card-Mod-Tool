# 2.0.30

新增实验功能：怪兽动画页面顶部的“魔法卡异画动画”。自动发现卡表和官方演出表中的同名魔法卡来源，不限于《增援》，包括《死者苏生》《墓穴的指名者》《融合派兵》等资源完整的组合。

选择目标卡号 → 来源卡号，检测资源后应用；可选择来源音效，默认保留目标原音效。卡图使用现有卡图替换功能单独处理，本入口不改变卡图或游戏效果。

复制全部玩家／时机登记，目标无登记时可新增并还原删除。保留首次备份，只还原目标卡，保留其他卡修改；未知外部修改、缺依赖、移动专用脚本或无直接 Timeline 的内部演出会阻止应用。必须退出游戏后操作。

隔离镜像发现 17 个来源组合，12 个资源完整组合通过写入与还原。通过四语界面检查及异常保护测试；未改写真游戏资源，游戏内播放尚未验收。此功能仍为实验功能，游戏更新后需要重新检测。
