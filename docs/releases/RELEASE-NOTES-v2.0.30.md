# 2.0.30 — FFmpeg 视频／GIF 导入兼容修复

- 修复截图中的 `Unrecognized option 'vsync' / Option not found`：视频和 GIF 抽帧不再发送废弃的 `-vsync`，改用 `-fps_mode passthrough`。
- 遇到不识别 `fps_mode` 的旧 FFmpeg，仅在确认为该选项不支持时重试一次，不发送帧同步选项，由已有 `fps` 滤镜控制帧率。清理前次临时输出；解码失败、损坏文件等仍保留实际原因，不无限重试，也不以兼容逻辑掩盖错误。
- 自动画质探测、固定分辨率、原分辨率 RGBA、起始秒／帧数限制和去绿幕共用修复后的抽帧入口。退出或取消时等待 FFmpeg 进程结束并清理临时帧。
- 导入完成或报错后恢复动画资源状态，不再停留在“正在低清探测实际帧数与画面比例”。已加载的动画在导入失败时保留。
- 修正左下角仍写死 `v2.0.27` 的版本标签，改为读取实际程序版本。

截图显示的是视频读取参数错误，不是 15994 的卡号或官方动画缺失。无需为此重建游戏资源索引、还原 Mod 或重装游戏。建议解压完整新版到独立目录，保留与 EXE 同级的 `data`，直接运行新版 EXE。

本机以发布包 FFmpeg 8.1.1 执行真实视频和 GIF 测试；旧参数不支持的分支使用模拟错误加真实抽帧验证。未取得截图电脑的 FFmpeg 和原视频，不宣称已在对方环境复现或验证全部编码格式。具体结果见 [验证记录](../testing/TEST-REPORT-v2.0.30.md)。

本版保留 2.0.29 的动画图集漏页与超框开关还原修复。14741／23487／23488 原生 Timeline 仍只做识别与诊断，不支持其播放／替换。手机端继续搁置，不新增无官方演出的动画，不向游戏进程注入。开发写回测试只用独立副本；真实游戏内召唤效果未验收。
