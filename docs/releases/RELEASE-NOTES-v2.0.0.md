# MD Card Mod Tool 2.0.0

发布日期：2026-08-30

## 2.0 核心修复

- 修复透明卡框在编辑预览中看似透明、写入 Texture2D 后却变成不透明的问题。Astellar Dirty Alpha 现在会对 PeriFrame、ArtFrame、EffFrame 的完整有效几何清零 Alpha，包括主体覆盖框线的交叠区域，同时从 ArtFrame／EffFrame 中排除 EffBox。
- 清零 Alpha 时保留原始 RGB，保证 Master Duel 卡片着色器仍可读取透明边缘颜色；另生成强制可见的编辑预览，不让 Windows 图像控件把隐藏 RGB 显示成黑块。
- 修复 PSD 图层提取时把源 Alpha 同时当作 paste mask，导致半透明边缘 Alpha 被重复相乘的问题；重新生成 16 套、共 96 张 Astellar 六层模板。
- 新增真实 22747 草稿只读回归：输出包含 140,051 个透明像素，其中 139,993 个透明像素保留非黑 RGB，预览 720,896 个像素全部可见；测试不会写入游戏 Bundle。

## 新功能

- Master Duel 风格单窗口工作区，侧栏只保留卡片资源、视觉资源、怪兽动画与设置；卡框／超框和 Mod 管理并入卡片资源的分类与上下文动作。
- 重新设计为深蓝黑侧栏、青色焦点与金色强调的现代化界面；使用用户提供卡图生成透明圆角应用图标，并按 DPI 缩放圆角、边框与导航图标。
- 简中、繁中、日语、英语界面即时切换；加入四语卡名与卡号搜索。
- 自动发现全部 Steam 库、真实安装目录及多个 LocalData 账号，并按游戏安装记住账号选择。
- 统一壁纸、大厅背景、决斗场地、卡套、头像、头像框、卡盒和硬币的预览、替换、恢复与 Mod 打包。
- 直接预览未替换的原版 Spine 4.2 怪兽动画；支持动画名称选择、循环、暂停、缩放和平移。
- 可把 GIF、视频或图片序列安全写入一张已有完整官方演出的怪兽，并同时替换其 HD／SD 资源；无官方演出的卡只读显示明确诊断。

## 重要修复

- 修复“当前 Bundle 无法按索引读取”“找不到可写入的 Texture2D／texture2”及游戏更新后旧 PathID、serialized file、Bundle 路径失效的问题。
- 兼容内嵌和流式 Texture2D 数据，以及 `m_ImageData`／`image data` 等字段表示。
- 透明超框使用保留透明像素 RGB 的 RGBA 解码与合成，避免黑边、暗边和预览失真。
- 图片预览改为可取消的版本化异步任务，统一位图所有权，降低高频切换时闪退与资源泄漏风险。
- 分类刷新改为单次事务，资源列表使用按需生成行的虚拟模式；解决大型索引加载时分类树短暂清空、计数显示 0 / 0 和列表卡顿的问题。
- 视觉资源快捷筛选改为按窗口宽度分配的 8 列布局，修复系统缩放后出现原生白色滚动条及筛选按钮横向溢出的问题。
- 动画资源按 region、tier 和 scale 配对；模板选择一次读取实际动画索引，避免重复路径探测。
- Spine 预览兼容 weighted deform、path、physics、linkedmesh、clipping、双色 tint、新旧 atlas 与非整数纹理缩放。
- 卡片资源预览下方操作重排为固定 2×4 网格，“卡图／卡框编辑”改为“制作超框”，且可直接读取当前游戏原卡图；怪兽动画页操作区改为三行自适应布局，圆角仅在绘制阶段完成，不再用会在 DPI 重排后残留旧字符的窗口 Region。
- 卡框／超框管理页移除旧式白色列表，映射表、表头、输入框与操作按钮统一为深色自绘和圆角样式，最后一列会随窗口及 DPI 自动填充。
- 卡名搜索只在卡片资源页显示，切换到视觉资源、怪兽动画或设置后不再保留旧查询；超框登记与 Mod 操作只在选择对应卡片分类时出现。
- 普通卡图预览改为显示 Texture2D 原图，不再因尺寸猜测自动叠加灵摆框；超框制作会从 Astellar 卡片类型与子类型推荐正确卡框，例如链接怪兽使用 `card_frame18`、灵摆效果怪兽使用 `card_frame14`。
- 导航状态切换会取消上一次 hover 动画并立即同步新调色板，修复内容已切页但旧栏目仍保持填充色、随后产生残影的问题。
- 四语目录、新卡图与官方动画索引的后台进度采用线程安全的“项目数＋时间”双重节流，并限制 AssetsTools 重型扫描并发。切换卡框或动画页时会先绘制本地化加载态、取消低优先级 Build 扫描，待旧解析任务退出后再读取目标 Bundle，避免 CPU／磁盘争用造成假死或“未响应”幽灵窗口。
- 怪兽动画卡号输入改为 IME 安全输入框，停止输入约 380 ms 后自动定位；Spine 帧生成过程中即开始预览，不再等待全部帧完成。
- Spine 预览修正 drawOrder 重建、Texture 与顶点颜色混合、slot／attachment tint、PMA 检测与反预乘，解决部分官方动画的图层顺序、发黑和透明边缘错误。
- 卡框资源明确分成 16 套 Floowan 普通卡框、16 套 Astellar 透明 RGB 卡框和 16 套 Floowan OfGradient 炫彩边缘框；制作超框可在三种模式间切换。新卡首次制作默认进入透明超框，Astellar 六层模式继续保留 Alpha=0 像素的 RGB。
- 普通卡和已有超框卡已统一为同一个“制作超框”编辑器，不再经过旧的裁剪中间窗口，也不要求先上传图片。编辑器直接读取当前 Texture2D；卡图可在最终 704×1024 卡面上拖动，以滚轮／滑杆缩放，并可更换卡图、添加或清除叠底背景。卡图变换参数会随草稿保存，重新打开后恢复。
- 超框合成顺序修正为“叠底背景 → 卡框／Astellar 六层 → 透明主体”，主体 RGB 可覆盖框线；最终 Dirty Mask 会对完整透明边缘清零 Alpha，不再因主体覆盖而变成不透明。编辑画布使用单独的可见预览，不会把隐藏 RGB 显示成黑块；三类卡框仍由像素级回归防止标签或素材互换。
- 异画／公开卡号与 MonsterCutIn 的 P 编号不一致时，会按四语同名卡查找完整官方演出。卡号 3899 现在保留为当前选择并只读播放 P13668，不会再误报“无官方动画”，也不会误写 P13668 的六件套。
- 原始动画资源页同样支持 3899 → P13668 只读回退：允许预览与导出，但禁止导入、替换、恢复及拖放写入；动画页底部动作重排为三行并移除控件 Region，连续加载后不再出现旧字符残影。
- 已正式移除“无官方动画新增”和运行时注入。分析确认仅创建六个 Bundle 并强制 `IsMonsterCutin` 资格仍缺少官方时间轴／内部登记，实机会卡顿且不播放；旧实验事务仍可一键还原或删除。

## 已知边界

- 只能预览和替换已经拥有完整官方召唤演出的怪兽；不能为没有官方演出的卡新增 Cut-in。
- 新卡会自动进入卡名与资源检索；只有本机已下载完整官方动画资源时才能预览或替换动画。
- 工具不会修改 `GameAssembly.dll`，也不会向游戏进程注入第三方 DLL。
- 2.0 使用独立发布目录，不修改原 `data24`；升级前建议保留自己的素材与备份目录。
