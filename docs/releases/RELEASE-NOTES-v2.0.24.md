# MD Card Mod Tool 2.0.24（本地测试版）

## Mod 管理

- 增加“导出选中 Mod”，支持 Ctrl／Shift 多选。按钮显示选中数量，未选择时禁用；原有“导出全部 Mod”保留。
- 选中卡片时，打包该卡已修改的卡图、关联官方动画 Bundle 和超框登记；独立的其他卡、视觉资源和已经还原的文件不纳入所选范围。同一 Bundle 只导出一次。
- 选中导出同样支持直接替换 ZIP（默认）与工具专用 Mod 包，保留目录、清单、SHA-256 校验及当前账号映射。
- 默认按修改时间由新到旧排列，新增时间列。排序菜单支持最新／最早／名称排序，点击时间列可切换升降序；排序偏好保存到全局设置。
- 排序、刷新和切换语言后保留仍在当前列表中的选择。搜索 Mod 时不会混入未修改或已还原的卡。
- Mod 列表统一包含卡片和视觉资源；卡片关联的动画改动也能从该卡条目选中导出。
- 操作栏按窗口宽度自动换行；新增控件沿用现有深色、圆角样式和四语切换。

## 使用

在卡片资源页左侧点击“Mod 管理”，选择一项或使用 Ctrl／Shift 多选，再点击“导出选中”。保存时选择直接替换 ZIP 或工具包。用排序菜单或时间列找到最近制作的 Mod。

导出以完整 Bundle 为单位，不拆分共享资源。若所选卡需要共享超框登记表，或多个资源位于同一图集，那个 Bundle 内其他卡的修改也可能随文件一起导出；导出前有明确提示。仅有关联动画改变的卡也会出现于 Mod 管理；“还原所选”仍还原图片 Bundle，动画请在怪兽动画页还原。

修改时间来自实际资源 Bundle 的文件时间，卡片关联动画取最新时间，公共超框表不会覆盖已有独立修改时间。导入、复制或外部改动文件后，时间可能随文件变化，不表示原创素材的制作时间。

本次测试只写临时资源副本，未修改真实游戏及其备份，旧工具版本保留。此本地测试版尚未上传 GitHub；原分辨率 RGBA32、单卡去闪卡内框等实验功能的原有验证边界不变。
