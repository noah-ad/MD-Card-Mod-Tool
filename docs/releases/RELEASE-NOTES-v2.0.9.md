# 2.0.9 — 动画比例校准与新卡更新

- 按用户指定，将新版 100% 定义为 2.0.8 的 140%：生成尺寸从 4800×2700 改为 6720×3780，50% 对应旧版 70%。不是仅修改显示标签。
- 预览以校准后的画布作为 100% 基准；读取旧单槽动画时从附件实际尺寸换算，旧 140% 显示为新版 100%，旧 100% 约为新版 71%。不会自动重写已安装 Mod。
- 包含 2.0.7／2.0.8 的动画文件占用预检、临时六 Bundle 构建验证及失败回滚、新卡卡名资源更新检测、22920 卡名识别，以及侧栏初始 DPI 修复。

使用：完全退出游戏，重新导入视频，以新版 100% 替换目标卡（例如 22524），然后启动游戏复测。非 16:9 素材保持原比例，可能留边；放大也可能裁掉边缘。

限制：140% 是用户指定的手动校准，不是从游戏相机参数推导的通用比例，不保证所有卡和分辨率均完全铺满。未进行真实游戏召唤验收。DPI 测试为初始 144/192 DPI 注入和布局模拟，不等于实际桌面／跨屏验证。写回回归只使用临时副本。
