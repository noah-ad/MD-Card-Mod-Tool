MD Card Mod Tool 2.0.1
==============================

首次启动
--------
发布目录根部只有 MD卡图查看替换器.exe 与 data 文件夹，直接双击根目录 EXE 即可。
若目录来自浏览器下载的 ZIP，请先运行 data\首次启动-解除下载封锁.bat。它只会移除
本发布目录中文件的 Windows 下载区域标记，以避免大型自包含 .NET 程序首次启动异常缓慢。
以后可直接运行根目录 EXE；data\启动 MD卡图查看替换器.bat 仅作为兼容入口。

游戏目录、账号与语言
--------------------
工具会从 Steam 的全部库自动查找 Master Duel，并列出全部 LocalData 账号。若未找到，
可在顶栏手动选择游戏根目录。顶栏还可切换简中、繁中、日语、英语；切换即时生效。

卡片与视觉资源
--------------
1. 进入“卡片资源”，在顶栏输入卡号或任一语言卡名。搜索框只在此栏目显示。
   输入过程中会显示 Astellar 四语候选；可用上下键选择，按 Enter 直接定位卡图。
2. 左侧只保留卡片资源、视觉资源、怪兽动画和设置四个主栏目。
3. 选中资源后可预览、导出、替换或还原。

卡框、超框和 Mod 管理都位于“卡片资源”：从资源分类选择“超框卡图”会显示超框登记
操作；选择“Mod 管理”会显示筛选、导入、导出和备份操作。普通资源预览只显示实际
Texture2D，不会自动叠加灵摆框；点击“制作超框”会直接打开统一编辑器。普通卡与已有超框卡
使用同一窗口，不再出现额外的裁剪中间页，也不要求先上传新图片。新卡首次制作默认使用
透明超框，并按卡片类型推荐正确框种。

在最终卡面上按住左键即可任意拖动卡图；使用滚轮或“卡图缩放”滑杆调整大小，方向键可微调，
Shift + 方向键可快速移动，双击恢复铺满。可随时“更换卡图”“添加叠底背景”或“清除背景”；
关闭并重新打开会恢复卡图位置与缩放。叠底背景会自动居中铺满为 704×1024，最终图层顺序为
“叠底背景 → 卡框 → 透明主体”。要形成自然的主体越框轮廓，应更换带透明通道的 PNG；普通
不透明图片仍可拖出框外，但边缘会保持矩形，编辑器会明确提示。

编辑器默认显示“游戏最终预览”，它与应用后主界面的预览使用完全相同的 RGB 投影，并禁止
误拖动。需要调整卡图时点击“构图编辑”；调整完成后切回“游戏最终预览”检查实际效果。
“导出游戏预览”导出的是这张可见检查图，写入 Texture2D 的数据仍保留原始透明 Alpha。

卡框资源分为三类：透明卡框、炫酷卡框、普通卡框，每类 16 套。普通与炫酷资源来自 Floowan／
master-duel-modding，透明 RGB 卡框和六层超框模板来自 Astellar；三类不会互换标签。
2.0 已修复透明卡框写入后变成不透明的问题。实际游戏贴图会在透明框几何处把 Alpha 清零，
但继续保留 RGB 供游戏着色器读取；编辑器预览会单独显示这些区域，因此预览可见不代表
写入贴图不透明。

视觉资源包括壁纸、大厅背景、决斗场地、卡套、头像、头像框、卡盒和硬币。决斗场地
页顶部提供上述类型的一级快捷筛选，不必再从分类树中寻找。决斗场地通常由 near、far
等多张材质组成，应按需要分别修改。若旧索引中的 Bundle、PathID 或
Texture2D 已失效，工具会重新定位并验证，不会在候选不明确时猜测写入。

怪兽动画预览
------------
在“怪兽动画”页输入卡号；停止输入约 0.4 秒后会自动定位并播放。也可输入卡名后点击
“预览动画”。带原生演出的怪兽无需先替换，即可选择动画名称并预览官方 Spine 动画；
生成首批帧后就会边渲染边播放，可循环、暂停、缩放和平移。
如果公开卡号与资源 P 编号不同，工具会按四语同名卡只读回退。例如输入 3899 会保持
当前卡号为 3899，并播放同名官方演出 P13668；这种回退不会把 P13668 当成 3899 的独立资源写入。

替换已有官方演出
----------------
1. 定位一张已经拥有完整官方召唤演出的怪兽。
2. 导入 GIF、视频或图片序列，调整帧率、画质、画面比例与绿幕透明化。
3. 完全退出 Master Duel。
4. 点击“写入 HD 与 SD 动画”并确认。

写入只会替换已定位的官方 HighEnd_HD／SD Texture、Atlas、Skeleton，并在写入失败时回滚。
没有官方演出的怪兽会明确显示“不支持新增动画”，导入与写入按钮不会启用。

原因是游戏播放召唤演出不只检查 IsMonsterCutin，还依赖官方时间轴与内部登记；单独新建
六个 Bundle 会让召唤短暂卡顿但不会播放。因此“给无动画怪兽新增演出”和运行时注入
已经下架。旧测试版若留下实验文件，动画页只保留预览及一键还原／删除，方便安全清理。

备份与还原
----------
首次修改已有 Bundle 前会备份到：

  <游戏目录>\_MD卡图备份\<资源类型>\...

旧测试版登记为 Created 的实验动画 Bundle 会在还原时删除。“卡片资源”分类树顶部的
“Mod 管理”可查看、恢复、导出与导入工具产生的改动。任何替换或还原操作前都应完全
退出 Master Duel。
